# GDN Phase One — v0.4.5rc11

Developer preview. GDN coordinates scoped engineering changes, configured checks, review, bounded repair and an evidence trail. Human approval remains mandatory. Includes a scripted demonstration, command-worker integration and a configurable local-model adapter. No bundled models, automatic upstream publication or telemetry.

The frozen RC11 passed 276 internal regression tests. The licensed distribution preserves the tested runtime, test code and synthetic fixture bytes. An upstream trial demonstrated the workflow with a single model across roles; independent-model inference, intended-host containment and comparative superiority remain unverified. Not for production use.

**GDN is not a security sandbox.** Real jobs require a reviewed disposable non-root Linux VM without credentials or sensitive mounts, externally enforced resource limits and loopback-only networking. Audit on an independent clean installation. Review SECURITY.md before running any job.
